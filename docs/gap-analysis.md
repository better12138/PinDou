# 拼豆工具差距与机会清单

> 对照对象：Bead Studio、PhotoPearls、Perler 官方工具、国内拼豆图纸生成/豆豆图纸类小程序、淘宝代画服务。
> 排序依据：P0 = 直接影响完成一件作品的可用性；P1 = 明显影响体验与转化；P2 = 差异化/增长向。

## 本轮已落地（详见代码）

- P0-1 性能：`src/WorkspaceCanvas.tsx` 拆分 ResizeObserver 与重绘、canvas 尺寸仅在变化时重置、hover 按格子节流、rAF 合并绘制。
- P0-2/3 板规格与 cm：`BoardSettings.beadSizeMm`、视图面板「拼豆板规格」、板数与成品尺寸展示。
- P0-4 备货：`suggestStock` + 用量面板 + Excel 列。
- P0-5 撤销边界：`toggleActiveLayerOnly` 前后快照修正。
- P0-6 色差：`palette.ts` 新增 `colorDistanceLab`（CIEDE2000 + Lab 缓存），用于最近色匹配与跨品牌色号对照。

## 明确不做（及原因）

- 移动端手势重构：涉及画布交互全面改写，风险高，建议单独排期。
- 社区/分享：需要后端、账号与内容审核。
- AI 风格化：外部模型成本与稳定性不可控。
- 库存全量系统：先验证「调色盘子集生成」需求强度。
